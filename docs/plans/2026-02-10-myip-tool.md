# Plan: My IP Tool

**Date:** 2026-02-10
**BA:** Claude (AI)
**Status:** DEV COMPLETE

## Overview

Build the "My IP" tool page from the `designs/myip` mockup. This tool displays the user's public IP address with technical information (ISP, country, city, coordinates), privacy flags (Proxy, VPN, Tor), timezone, and a live location map.

The design uses a clean, solid-card style (white cards with subtle slate borders) — different from the existing `ipcheck` glass-morphism approach. This is a separate tool at `/tools/myip`.

## Design Analysis

### Layout Structure
1. **Header** — Existing shared header (reuse `components/layout/header.tsx`, already has search + sign in)
2. **Hero Section** — "YOUR PUBLIC IP ADDRESS" label, large IP (5xl→7xl), copy button, "Connection Secure & Private" shield text
3. **Content Grid** — 12-column grid:
   - Left (7 cols): "Technical Information" panel with 2x2 info cards + 4-column flags row
   - Right (5 cols): "Live Location" map panel with fullscreen button
4. **Footer** — Reuse existing footer (adapt if needed)

### Visual Style (differs from ipcheck)
- Cards: `bg-white dark:bg-navy-900` with `border border-slate-100 dark:border-slate-800`, `rounded-xl shadow-sm`
- Info cards inside tech panel: `bg-slate-50 dark:bg-slate-800/50` with `border border-slate-100 dark:border-slate-700`
- Icon boxes: White background `bg-white dark:bg-slate-700` with shadow (not primary tint like existing `icon-box.tsx`)
- Primary color: `#137fec` (design) — we'll use our existing `--ht-color-primary-*` tokens instead
- Flags row: color-coded values (red=No proxy, green=Yes VPN, default for Tor/Timezone)

### Components to Reuse
- `components/ui/copy-button.tsx` — for copy IP action
- `tools/ipcheck/location-map.tsx` — Leaflet map (extract to shared or duplicate for myip)
- `components/layout/header.tsx` — existing header
- `components/layout/footer.tsx` — existing footer

### New Components Needed
- `tools/myip/myip-hero.tsx` — Hero section with IP display + copy + secure text
- `tools/myip/tech-info-panel.tsx` — Technical information panel (2x2 grid + flags row)
- `tools/myip/live-location-panel.tsx` — Map panel wrapper with header + fullscreen button
