Mood Board — Layout Approach

How should the overall experience be structured?

A

Wizard → Canvas (Guided Start)

Step 1: Full-screen "Create" wizard — theme input, style preferences, color mood picker. Feels like a creative brief.

Step 2: Generated board opens in a full-screen canvas (no sidebar). Tools appear in a floating toolbar or slide-out drawer.

Best for: Non-designers who need hand-holding. Reduces blank-canvas anxiety.

Trade-off: Extra step before seeing results. Power users may find it slow.

B

Inspiring Empty State → Sidebar Studio

Landing: Instead of blank canvas, show template gallery / example boards / trending themes. One click to start.

Studio: Keep sidebar + canvas split but redesign both — collapsible sidebar, better canvas with snap-to-grid, zoom/pan.

Best for: Familiar pattern (Figma/Canva-like). Works for both audiences.

Trade-off: Sidebar takes screen space. Mobile experience harder to get right.

C

Chat-Driven Generation → Full Canvas

Start: Conversational prompt interface — "Describe your project and I'll create a mood board." AI asks follow-up questions.

Result: Board generates into full-screen canvas. Floating chat bubble for "add more" / refinements.

Best for: Most approachable for non-designers. AI does the heavy lifting.

Trade-off: Less direct control. May feel too "AI-generated" for designers.

My recommendation: A (Wizard → Canvas) — It solves the empty state problem completely, gives non-designers confidence, and the full-screen canvas gives more room for the board. Power users can skip through the wizard quickly.
