# Google Stitch Prompt — NZ WorkSafe H&S Toolkit

## Screen Overview

NZ health & safety compliance toolkit with 4 tabs: H&S Plan generator, Hazard Register, Incident Reports, Worker Engagement checklist. Dark theme, utility blue ToolFrame.

**Platform:** Responsive web (desktop 1440px, mobile 390px)
**Theme:** Dark mode with Toolk1t utility blue

## ToolFrame

Utility blue gradient header: back arrow + shield/hardhat icon + "WorkSafe Toolkit". 4 tabs: Plan | Hazards | Incidents | Workers

## Tab 1: Plan — industry cards (6, 2-col grid) with hardhat/fork/desk/cart/tractor/gear icons → questions (yes/no pills) → plan preview card → Download PDF button

## Tab 2: Hazards — pre-populated list per industry. Each row: hazard name + risk badge (green/amber/red/purple) + controls + responsible + edit/delete. "Add Hazard" button opens form modal. Risk matrix: likelihood × consequence.

## Tab 3: Incidents — single form card with date/time/location/type/description/people/injuries/actions/root-cause/corrective fields. Notifiable event warning banner (red). Generate PDF button.

## Tab 4: Workers — 10-item checklist with Yes/Partially/No pills. Score circle (0-100). Failed items show amber recommendation cards.

## Mobile: all stacks vertically, cards full width, 44px touch targets.
