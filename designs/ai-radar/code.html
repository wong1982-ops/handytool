GPT-5o Released with Extended Reasoning and Multimodal Code Generation

OpenAI · 3 April 2026

image Model preview image
GPT-5o OpenAI LLMs

Summary

OpenAI's GPT-5o marks a significant leap in reasoning and multimodal code generation. The model natively executes code within vision and language workflows — enabling it to analyse charts, debug screenshots, and produce runnable scripts without external tools. With a 1M token context window, GPT-5o can process entire codebases in a single call. Benchmark scores show top-tier results on MATH (92.4%), HumanEval (97.1%), and MMLU (91.8%). The model is available via API with structured output and function calling support.
